Interactive Tutorial Flow

This page is both a dev harness and an end-user style walkthrough of the runtime contract. Work from top to bottom to see state sync, stream updates, cancellation, and lazy hydration in one pass.

  1. Use the Orders table to try sorting, filtering, segmented controls, action menus, and header-based state persistence.
  2. Trigger SSE refresh / prepend / append updates from the top action buttons.
  3. Use Session Persistence Table to confirm state survives reload via sessionStorage.
  4. Use Request Cancellation Demo to verify stale responses are ignored.
  5. Scroll to the bottom to trigger Lazy Summary hydration.
