# Changelog

All notable changes to this project should be documented here.

This project follows a lightweight pre-1.0 changelog format. Breaking changes
are allowed while the package remains alpha, but they should be called out
explicitly.

## 0.1.0 - Unreleased

- Initial Python package with Jinja/Bootstrap macros.
- First-party TypeScript runtime for server-rendered component replacement.
- Stateful table contract with filtering, paging, sorting, persistence, and
  conditional fragment responses.
- SSE support for replacement and row-level append/prepend updates.
- Flask and Go example applications sharing the same Jinja templates.
- Agent-facing authoring and migration guidance.
- Semantic versioning policy and generated macro API reference.
